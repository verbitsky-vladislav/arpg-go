# Pixel ARPG

[![CI](https://github.com/verbitsky-vladislav/arpg-go/actions/workflows/ci.yml/badge.svg)](https://github.com/verbitsky-vladislav/arpg-go/actions/workflows/ci.yml)
[![Go](https://img.shields.io/badge/Go-1.24-00ADD8?logo=go&logoColor=white)](https://go.dev)
[![Ebitengine](https://img.shields.io/badge/Ebitengine-2.9-e6b422)](https://ebitengine.org)

Пиксельная ARPG с видом сверху на Go и [Ebitengine](https://ebitengine.org):
остров, который генерируется заново под каждого героя, тридцать видов зверья,
шестьдесят разновидностей врагов, вещи, снаряжение, опыт и украденные у мёртвых
умения.

![остров вблизи](docs/media/world-detail.png)

Проект пишется как учебник самому себе, поэтому у каждого решения записана
причина. Формат — не «как вызвать функцию», а «почему сделано так и чем плохо
иначе»: 3800 строк документации в [`docs/`](docs) — такая же часть работы, как
код. Комментарии в коде из той же школы.

```bash
go run ./cmd/game
```

Go 1.24+, ассеты читаются с диска — правка PNG видна без пересборки.

## Что уже есть

### Мир

Карта собирается генератором из купленного тайлсета: манифест биома говорит,
какой тайл чем является, дальше всё считается — форма острова, вода, тропы,
плато с обрывом, лестницы, декор.

| весь остров (160×160 тайлов) | вблизи (окно игры 1:1) |
|---|---|
| ![карта](docs/media/world.png) | ![вблизи](docs/media/world-detail.png) |

- **Угловой dual-grid автотайлинг** вместо blob-47: стык считается по четырём
  углам клетки, а не по восьми соседям — набор тайлов получается втрое меньше и
  ложится на реальные покупные листы ([`autotiling.md`](docs/worldgen/autotiling.md)).
- **Три уровня высоты**: вода, нижняя земля, плато с обрывом и лестницами.
  Обрыв ставится процедурно — художник размечает только края
  ([`layers_and_plateau.md`](docs/worldgen/layers_and_plateau.md)).
- **13 проверок на каждую карту** (E1…E15): суша не подходит к краю, на плато
  можно подняться, пропсы не в воде и не друг в друге, точка появления на суше.
  Не прошло — генератор ругается, а не отдаёт битую карту.
- Карта — данные ([map_format v1](docs/worldgen/map_format.md)), а не картинка:
  ими же живёт игра и они же лежат в сохранении.

```bash
go run ./tools/worldgen assets/biomes/forest -seeds 6   # карты + отчёт валидации в out/
```

### Герой

Восемь направлений, автомат состояний, удар сектором.

![герой](docs/media/hero.gif)

Диагонали в паках не нарисованы — они **дорисованы** нами
([`tools/dir8`](tools/dir8)): по текстовым сеткам из четырёх исходных рядов, с
покадровыми сдвигами головы и оружия. Оружие перекрашивается тем же приёмом:
палка — это меч, у которого сменили материал ([`tools/weaponskin`](tools/weaponskin)).

Состояний шесть (покой, шаг, бег, удар, боль, смерть), и выбираются они **по
вводу, а не по наличию анимации**: чего в паке нет, то подменяется по таблице
деградации — ударить можно всегда, даже если клипа удара не существует
([`character.md`](docs/character/character.md)).

### Бой и вещи

41 предмет: материалы с мобов, оружие, снаряжение, камни украденных умений.

![вещи](docs/media/items.png)

- **База отдельно, оружие отдельно.** Кулаками — 1–2, палкой — ровно 2–4:
  вещь не дополняет базовый урон, а замещает его целиком, поэтому число над
  целью сходится с числом в таблице ([`combat.md`](docs/character/combat.md)).
- **Урон разведён по видам** (физический, огонь, холод, молния), хотя вид пока
  один: сложить в одно число дёшево, разложить обратно — уже нет.
- **Кража силы.** С убитого врага падает камень с его собственной атакой —
  дыхание демона, залп бехолдера. Он ложится в одну из трёх ячеек (Q/E/R), у
  него считанные заряды, и чем крепче была тварь, тем меньше их дадут.
- Сумка по ячейкам, снаряжение по гнёздам, сундуки на карте:

| снаряжение | сундук |
|---|---|
| ![снаряжение](docs/media/ui-equip.png) | ![сундук](docs/media/ui-chest.png) |

### Враги

18 типов по три силы — 60 разновидностей, плюс усиленные особи (★).

![враги](docs/media/enemies.gif)

- **Три канала восприятия.** Зрение — только в свой сектор `fov_deg` (со спины
  враг не видит — это право игрока подкрасться), слух — по коридорам, а не
  сквозь скалу, боль — всегда ([`enemies_ai.md`](docs/mobs/enemies_ai.md)).
- **Отряды.** Гуманоиды бьют строем и зовут подмогу; характер (`temper`) даёт
  профиль поведения, семья (`family`) — поправку к нему.
- **Бюджет опасности вместо голов.** Один демон и восемь крыс — не одно и то же,
  поэтому карта держит не число тварей, а сумму их опасности; отдельный лимит
  сторожит, чтобы вся карта не сошлась на игроке
  ([`enemies_spawn.md`](docs/mobs/enemies_spawn.md)).
- Уровень существа **не записан**, а выведен из его hp и урона — записанное
  число разъезжается с балансом при первой же правке
  ([`progress.md`](docs/character/progress.md)).

### Звери

30 видов: дикие и домашние, детёныши вырастают во взрослых.

![звери](docs/media/animals.gif)

Живут своей жизнью вокруг игрока: никто не появляется в поле зрения и никто не
копится там, куда игрок не вернётся ([`spawn.md`](docs/mobs/spawn.md)).

### Забег

- **Три персонажа**, у каждого свой мир, своя добыча и свой счёт убитых.
- **Мир сохраняется целиком**, а не сидом: генератор правится каждый день, и
  тот же сид завтра дал бы другую карту — с сундуком посреди озера
  ([`save.md`](docs/save.md)).
- Опыт, уровни, добыча с убитых — петля «убил → выпало → стал сильнее»
  замкнута ([`loot.md`](docs/mobs/loot.md)).
- Бестиарий, журнал персонажа (кого и сколько убил), настройки с
  переназначением клавиш.

### Звук

Синтезируется кодом, а не покупается: короткий абстрактный звук проще
сгенерировать, чем найти — он правится одной цифрой, у него нет лицензии, а
вариации бесплатны. Главный приём набора — не форма волны, а свип фильтра:
именно уезжающий вниз срез делает из шума замах ([`sound.md`](docs/sound.md)).

```bash
go run ./tools/sfxgen   # эффекты  → assets/audio/sfx
go run ./tools/musgen   # музыка   → assets/audio/music
```

## Управление

| действие | клавиша |
|---|---|
| ходьба | `W` `A` `S` `D` |
| бег | `ПРОБЕЛ` |
| удар | `ЛКМ` (дубль — `C`) |
| умения (украденная сила) | `Q` `E` `R` |
| сумка | `I` |
| открыть (сундук) | `V` |
| карта | `TAB` |
| пауза | `ESC` |

Герой смотрит и бьёт в сторону курсора, а идёт куда угодно — хоть отступая от
того, кого рубит. Всё переназначается в настройках.

## Устройство

```
cmd/game            точка входа: окно, загрузчик ресурсов, меню
internal/
  worldgen          генератор карт: высоты, вода, тропы, плато, автотайлинг, валидация
  world             карта в игре: тайлы, слои, физика, камера
  scene             экраны: меню, забег, персонажи, бестиарий, сундук, снаряжение
  character         герой: таблица, автомат состояний, анимация
  mob               звери, враги, ИИ, отряды, спавн, добыча, кража силы
  combat            числа удара: база героя плюс вещь в руке
  item              каталог, сумка, снаряжение
  progress          уровни, опыт, очки
  save              три персонажа, мир на диске
  audio             банк звуков и правила проигрывания
  sprite anim gfx   спрайт-паки, клипы, отрисовка
  ui settings       полосы, окна, курсор, настройки и клавиши
assets/             купленные паки, нормализованные и размеченные манифестами
docs/               каноничные описания форматов и правил
tools/              генераторы и просмотрщики (ниже)
```

38 000 строк Go, 237 тестов. Тесты стерегут не только код, но и **данные**:
что каждая пара «тело × оружие» рисуется во всех состояниях, что полосы опыта
не разъехались с балансом, что ни один моб не уходит без добычи.

```bash
go test ./...
```

## Чего ещё нет

- **биомов** — из двенадцати задуманных сделан один (лес); остальным нужны
  манифест и разметка тайлсета;
- **боссов** — описан и нарисован один (слизь), боевой сцены под них нет;
- **дерева пассивок** — задумано плотным кругом в духе PoE, в игре его нет;
- **локаций** — подземелья, деревни и пещеры лежат ассетами, генератора под
  них ещё нет;
- **сюжета и смены дня и ночи** — данные под ночь есть, самой ночи нет.

## Ассеты

Графика — купленные паки [CraftPix](https://craftpix.net) в нормализованном
виде. Они лежат в репозитории, чтобы игра собиралась одной командой, но
распространять их отдельно нельзя: лицензия у них своя, и на код проекта она не
распространяется. Звук — свой, синтезированный (`tools/sfxgen`, `tools/musgen`).
