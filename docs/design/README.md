> Особенность нашего арта: **всё делается кодом, без готовых пресетов**. Два
> пути: (1) процедурная отрисовка в рантайме из пиксельных карт (игрок, мобы,
> снаряды — пакеты `gfx`/`art`); (2) PNG-спрайты героев, тоже сгенерированные
> кодом (генератор из `base.png`), встроены в бинарник и проигрываются покадрово
> (пакеты `assets`/`anim`/`hero`). Подробности — `art-direction.md` и
> `../tech/architecture.md`.
