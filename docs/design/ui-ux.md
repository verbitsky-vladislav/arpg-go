# UI/UX — язык компонентов

Статус: 🟡 черновик (MVP-объём)
Связь: `screens.md` (карта экранов), `../mechanics/*`, `../progression/skill-tree.md`,
код — `internal/ui` (виджеты, HUD), `internal/scene`

Здесь — **язык интерфейса**: боевой HUD, панели, виджеты, обратная связь, цвета,
управление. Карта экранов и переходы — в `screens.md` (не дублируем).

## Принципы

- **Читаемость прежде всего** (пиллар «глубина PoE, ясность героическая»): яркий,
  контрастный, «жирнопиксельный» UI; в бою — минимум клаттера, глубина — в панелях.
- **Цвет кодирует смысл** — типы урона, типы защиты, редкости (см. «Цвета»). Игрок
  считывает угрозу/предмет по цвету мгновенно.
- **Мгновенный фидбек** на каждое действие (урон, попадание, левелап, подбор).
- **Диегетично, но функционально** — глобусы жизни/маны, слоты-«кукла», как в ARPG.

## Боевой HUD (экран Play)

```
┌──────────────────────────────────────────────────────┐
│ Ур.5 [▓▓▓▓▓░░░ XP]              Волна 3   врагов ×12   │  верх: уровень+опыт, волна, счётчик
│                                                        │
│                  · игровое поле ·                      │
│                 [🔥][❄] над врагом                      │  статус-иконки над целями
│              (числа урона всплывают)                   │
│         [🔥][💧] над героем (баффы/дебаффы)             │
│                                                        │
│  ◍◍                                            ◍◍       │
│  ◍◍ жизнь        [1][2][3][4]  скилл-бар      ◍◍ мана  │  низ: шары + панель скиллов
└──────────────────────────────────────────────────────┘
```

Компоненты HUD:
- **Шар жизни** (слева-низ) и **шар маны** (справа-низ) — заполнение снизу. *(есть в коде)*
- **Полоса опыта + уровень** — сверху-слева.
- **Счётчик волны + врагов** — сверху-справа (структура «арена с волнами»).
- **Скилл-бар** — низ-центр: слоты активных скиллов (по сокетам брони), в каждом
  иконка + **обводка-кулдаун** (радиальная) + затемнение при нехватке маны.
- **Статус-иконки:** над героем (баффы/дебаффы на нём), над врагами (наложенные
  статусы: горит/заморожен/шок и т.п.).
- **Числа урона** — всплывают над целью, **цвет = тип урона**; крит крупнее/ярче.

## Панель экипировки + сокеты (экран/оверлей)

```
┌── Экипировка ─────────────────────┐
│        [ Шлем ]                    │
│ [Оружие] [ Нагрудник ] ← «кукла»   │   слот на каждый тип вещи
│        [Перчатки] [Сапоги]         │
│ ── Сокеты нагрудника ──────────────│
│  (◒ Огн.шар)(◒ +Огонь)(◯)(◯)       │   гемы: скилл / поддержка / пусто
│ ── Подобрано / на земле ───────────│
│  [🗡][🛡][🥾]  → клик = надеть       │
│  Тултип: тип защиты, числа, сокеты │
└───────────────────────────────────┘
```

UX:
- **Слоты-«кукла»** (оружие/нагрудник/шлем/перчатки/сапоги) — по одному на тип.
- Подобранный предмет → клик по слоту надевает; старый снимается.
- **Сокеты** экипированной брони: клик/дроп вставляет **скилл-гем или поддержку**
  (`../mechanics/skills.md`); подсветка «нет брони → некуда вешать скилл».
- **Тултип** предмета: тип защиты (цветом), числа (броня/уклон/ЭЩ), число сокетов.
- MVP: рюкзак-сетки нет — только надевание (см. `../mechanics/items.md`).

## Экран дерева прогрессии

```
┌── Дерево (очков: 3) ──────────────┐
│      ·─○─○─◆ (Заметный)           │
│   [СТАРТ]─○─○─·  ...               │   пан/зум по большому полю
│      ·─○─◆─○─·                     │
│  Тултип узла: +эффект / требования │
└───────────────────────────────────┘
```

UX:
- Большое поле, **пан/зум**; узлы: свободные / доступные (подсвечены) / взятые.
- **Счётчик очков** сверху; клик по доступному узлу — взять (при наличии очка).
- **Тултип узла**: что даёт (по тегам/статам), Заметные — выделены.
- Старт героя подсвечен. Дерево — **отдельный экран** (`../progression/skill-tree.md`).

## Обратная связь / game feel

- **Числа урона** над целью, цвет по типу; крит — крупнее.
- **Хит-флеш** (враг мигает) + лёгкий **screen shake** на тяжёлых ударах.
- **Статус-визуалы:** горящий — оранжевый тлен, заморожен — синий лёд/замедление,
  шок — жёлтые искры (иконка + подсветка модели).
- **Левелап:** вспышка + индикатор «есть очко дерева».
- **Подбор лута:** предмет виден на земле → притяжение/подбор → короткий поп.
- **Низкая жизнь:** красная виньетка по краям экрана.

`#46d06a` · Энергощит `#46a0ff`.

## Управление (MVP)

| Ввод | Действие |
|------|----------|
| WASD / стрелки | движение |
| Мышь | прицел |
| ЛКМ | основной скилл / базовая атака (кулак, если нет скилла) |
| 1–4 | скиллы из сокетов |
| ЛКМ по луту / E | подобрать |
| I или Tab | экипировка |
| T | дерево |
| Esc | пауза |

## MVP-объём

- **В MVP:** боевой HUD (шары/XP/волна/скилл-бар), панель экипировки + сокеты,
  экран дерева, статус-иконки и числа урона, базовый фидбек.
- **Позже:** настоящий шрифт, рюкзак-сетка, подсветка редкостей, полоса босса,
  миникарта, анимации панелей.

## Связь с пилларами

- **Глубина PoE, ясность героическая:** глубину прячем в панели, HUD держим чистым;
  цвет-коды делают сложность считываемой.
- **Рост ощущается:** левелап/лут/узел дерева дают явный визуальный фидбек.
