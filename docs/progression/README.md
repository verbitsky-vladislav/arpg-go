# Progression (развитие)

Вынесено отдельно: как растёт сила игрока и как разворачивается игра в целом.
Это то, что удерживает в игре десятки часов.

Легенда: 🟢 в игре · 🟡 частично/черновик · ⚪ задумано

| Раздел | Файл | Статус |
|--------|------|--------|
| Рост персонажа (уровни, атрибуты, ресурсы) | character-progression.md | 🟡 |
| Дерево прокачки | skill-tree.md | 🟡 |
| Прогрессия игры (акты, сложность, эндгейм) | game-progression.md | ⚪ |
| Кривые силы (игрок vs мобы vs боссы) | power-curve.md | ⚪ |

Файлы со статусом ⚪ ещё не созданы — заводим по мере обсуждения.

> Прогрессия опирается на механики (`../mechanics/`): урон, защита, умения, лут.
> Сначала стоит зафиксировать их, потом строить кривые роста.
