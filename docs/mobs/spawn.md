# Заселение карты животными (`spawn.json`)

Каноничное описание [assets/mobs/animals/spawn.json](../../assets/mobs/animals/spawn.json)
и правил, по которым работает [internal/mob/spawner.go](../../internal/mob/spawner.go).

Схема взята из майнкрафта: популяция живёт вокруг игрока, а не по всей карте
сразу. Никто не появляется в поле зрения и никто не копится там, куда игрок не
вернётся.

---

## 1. Разделение с `species.json`

| вопрос | где ответ |
|---|---|
| **кто** водится и как часто | `species.json` → `habitat.biomes` (биом → вес) |
| **где** внутри карты | `species.json` → `habitat.zones`, `avoid`, `needs_settlement` |
| **сколько** их и **когда** появляются | `spawn.json` (этот файл) |

Порядок выбора при спавне — как в майнкрафте: **сначала место, потом житель**.
Спавнер берёт случайную точку, спрашивает у карты её зону и только затем
разыгрывает вид, которому эта зона подходит. Обратный порядок (выбрать вид, потом
искать ему место) на карте с одним озером выродился бы в бесконечный поиск.

---

## 2. Радиусы (`radius`, мировые пиксели)

```
        despawn 1200
   ┌───────────────────────┐
   │   keep 1000           │      spawn_min 400 — ближе никто не появляется
   │  ┌─────────────────┐  │      spawn_max 800 — дальше не появляется
   │  │  spawn_max 800  │  │      keep      — ближе этого никого не снимаем
   │  │   ┌─────────┐   │  │      despawn   — дальше снимаем сразу
   │  │   │  400    │   │  │
   │  │   │  ┌───┐  │   │  │
   │  │   │  │ @ │  │   │  │      @ — игрок, экран 640×360
   │  │   │  └───┘  │   │  │
```

- `spawn_min` **обязан** превышать полудиагональ обзора (`√(640²+360²)/2 ≈ 367`),
  иначе игрок увидит появление зверя из воздуха. Это проверяется тестом.
- Между `keep` и `despawn` особь снимается не сразу, а по шансу
  (`despawn_chance` за проверку раз в `despawn_interval_ticks`): популяция
  рассасывается постепенно, а не хлопком, когда игрок отошёл на шаг.
- Дальше `despawn` — снимается сразу.
- Особи с флагом `Animal.Persistent` (прирученные, сюжетные, поставленные
  вручную) не снимаются никогда.

## 3. Лимиты (`limits`)

| поле | смысл |
|---|---|
| `global` | всего животных на карте |
| `near` | в радиусе `keep` вокруг игрока — цикл спавна останавливается, когда столпилось |
| `per_species` | одного вида на карте |
| `per_species_overrides` | штучные исключения: буйволов 4, овец 12 |

Ограничивает первый достигнутый предел. Овец допустимо двенадцать, потому что
они ходят стадом (`spawn.group` до 6), а буйволов четыре — иначе стадо крупных
животных съедает весь `global`.

## 4. Темп (`rate`)

Раз в `interval_ticks` спавнер берёт `attempts` случайных точек в кольце и
пытается высадить **одну** группу — не больше, иначе карта наполняется рывком.
Внутри группы каждой особи даётся `place_tries` попыток встать в пределах
`group_spread` от центра; не нашла места (вода, край карты, чужая зона) — эта
особь просто не появляется.

Размер группы и выводок при взрослом берутся из `species.json`
(`spawn.group`, `spawn.with`), поэтому овцы приходят стадом, а лиса одна.

## 5. Остальное

| поле | смысл |
|---|---|
| `initial_fill` | доля `global`, до которой карта заселяется при создании |
| `activity_mismatch_weight` | множитель веса для вида, активного в другое время суток (`0` — запретить совсем) |

`initial_fill` нужен по той же причине, что и в майнкрафте, где мирные звери
расставляются при генерации: без него игрок стартует на пустой карте и первые
полминуты смотрит, как она наполняется.

`activity_mismatch_weight` не запрещает дневным видам появляться ночью, а
придавливает их вес: ночью лес принадлежит кабану и лисе, но встретить оленя не
невозможно. Время суток спавнер получает снаружи (`Update(..., night)`) — часов
в игре пока нет.

## 6. Что нужно от игрового слоя

Спавнер работает поверх интерфейса `mob.SpawnWorld`:

```go
Walkable(p) bool   // из mob.World
Water(p) bool      // из mob.World
Biome() string     // ключ в habitat.biomes
Zone(p) string     // water|shore|meadow|woods|trail|plateau|farmyard
Size() (w, h)      // размеры мира
```

Зоны совпадают со слоями worldgen (см.
[layers_and_plateau.md](../worldgen/layers_and_plateau.md)), так что своя
разметка карты спавнеру не нужна. Зона `farmyard` пока не генерится — поэтому
виды с `needs_settlement: true` в дикой карте не появляются вовсе. Это ожидаемое
поведение, а не поломка: в лесу заводятся кабан, лиса, олень, заяц, тетерев и
утки на озере.

Дальше — три вызова:

```go
s := mob.NewSpawner(cfg, cat, world, packs, rng)
s.Populate()                            // при создании карты
s.Update(playerPos, true, night)        // каждый тик
for _, a := range s.Animals() { … }     // отрисовка, попадания
```

Хищникам спавнер сам подставляет ближайшую жертву из `threat.prey` — зверь про
популяцию ничего не знает, соседей ему выдаёт тот, кто их держит.
