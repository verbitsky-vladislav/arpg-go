# Виды животных — описательные данные (`species.json`)

Каноничное описание формата [assets/mobs/animals/species.json](../../assets/mobs/animals/species.json):
что за зверь, дикий или домашний, нападает ли, во что вырастает, где водится.

---

## 1. Зачем отдельный файл

Рядом со спрайтами уже лежит `manifest.json`, но он описывает **только графику**
(размер кадра, направления, список анимаций) и **генерируется** нормализатором
`tools/assetnorm` — любые ручные поля в нём затрутся при перегенерации.

Поэтому смысловые данные живут отдельно:

| файл | что описывает | кто пишет |
|---|---|---|
| `<вид>/manifest.json` | кадры, размеры, анимации | генератор (`assetnorm`) |
| `animals/species.json` | вид, повадки, среда обитания, дроп | человек (баланс) |

Один файл на всех, а не по файлу на вид: 30 видов балансируются таблицей, а не
хождением по папкам. Формат **единый** — у каждого вида присутствуют все ключи,
даже пустые (`null`, `[]`, `0`). Отсутствующих ключей быть не должно: загрузчик
не подставляет умолчания, а валидатор ловит расхождение набора ключей.

Ключ записи == имя папки со спрайтами == `art`.

## 2. Поля

### Кто это

| поле | тип | смысл |
|---|---|---|
| `art` | string | папка со спрайтами внутри `assets/mobs/animals/` |
| `title.ru` / `title.en` | string | отображаемое имя |
| `family` | enum | `canine`, `feline`, `equine`, `bovine`, `caprine`, `suid`, `leporid`, `cervid`, `fowl`, `waterfowl`, `game_bird` — родня; по ней удобно вешать общие звуки, дроп, реакции |
| `size_class` | enum | `tiny`/`small`/`medium`/`large` — **смысловой** размер (масса, отбрасывание, приоритет y-сортировки). Пиксельный размер кадра берётся из `manifest.json`, здесь не дублируется |

### Домашнее / дикое и взросление

| поле | тип | смысл |
|---|---|---|
| `domestication` | enum | `wild` \| `domestic` |
| `stage` | enum | `adult` \| `young` |
| `grows_into` | id \| null | во что вырастает детёныш (`buffalo_cub → buffalo`) |
| `young_form` | id \| null | обратная ссылка: детёныш этого взрослого |

Ссылки должны быть симметричны; исключения (`drake` — второй взрослый для
`duckling`, `piglet` — взрослой свиньи в паке нет) отмечены в `notes`.

### Характер и агрессия

| поле | тип | смысл |
|---|---|---|
| `temper` | enum | `passive` — пасётся, от удара коротко убегает; `skittish` — убегает от игрока заранее; `territorial` — атакует при вторжении в радиус; `predator` — охотится на `threat.prey`, от игрока убегает; `tame` — держится рядом с игроком/двором |
| `activity` | enum | `day` \| `night` \| `any` — на будущий цикл суток |
| `threat.attacks` | bool | **может напасть** вообще |
| `threat.unprovoked` | bool | нападает первым, без удара по нему (кабан, гусь) |
| `threat.damage` | int | урон удара |
| `threat.sight` | int | радиус обнаружения, px мира |
| `threat.flee_hp` | float | доля hp, ниже которой удирает (`1.0` = убегает всегда, не дерётся) |
| `threat.prey` | id[] | на кого охотится (пищевая цепочка, только для `predator`) |

`attacks: true` при отсутствующем клипе `attack` — норма: анимация есть только у
кабана, остальным движок подставляет рывок на `walk` (см. §5). Числа урона и
здоровья — в §4.

### Среда обитания

Двухуровневая: биом (какая карта) + зона (какое место на карте).

| поле | тип | смысл |
|---|---|---|
| `habitat.biomes` | map id→вес | id каталога в `assets/biomes`; вес — относительная частота спавна именно в этом биоме |
| `habitat.zones` | enum[] | где внутри карты: `water`, `shore`, `meadow`, `woods`, `trail`, `plateau`, `farmyard` |
| `habitat.avoid` | enum[] | куда не заходить при блуждании (жёстче, чем «не спавнить») |
| `habitat.needs_settlement` | bool | спавнится только рядом с постройкой/фермой, не в чистом поле |

Зоны намеренно совпадают со слоями, которые **уже выдаёт worldgen**
(см. [layers_and_plateau.md](../worldgen/layers_and_plateau.md)), чтобы спавнеру
не потребовался свой анализ карты:

| зона | источник |
|---|---|
| `water` | заливка `water_color` / уровни `stageLevels` |
| `shore` | разрежённый слой `coast` (`grass_water`/`mud_water`) |
| `meadow` | `ground` (трава) без объектов сверху |
| `woods` | `ground` под объектами-деревьями |
| `trail` | `mud` (тропы `stageTrails`) |
| `plateau` | `plateau` (верх возвышенности) |
| `farmyard` | окрестности построек из `assets/locations` — **ещё не генерится** |

`cliff` (тело обрыва) в списке зон нет — туда никто не спавнится; в `avoid` его
указывать можно.

### Спавн, польза, дроп

| поле | тип | смысл |
|---|---|---|
| `spawn.group.min/max` | int | размер группы (овцы стадом, цыплята выводком) |
| `spawn.with` | id \| null | спавнится рядом со взрослым этого вида (детёныши при матке) |
| — | — | *сколько особей держать на карте и на каком удалении от игрока — не здесь, а в [spawn.json](spawn.md)* |
| `stats.hp` | int | здоровье |
| `xp.min/max` | int | полоса опыта за убийство; у безобидной дичи вдвое ниже полосы своего уровня (см. [прокачку](../character/progress.md)) |
| `stats.speed.walk/run/swim` | int | px/с; `run` заполняется даже без клипа `run` — фолбэк ускоряет `walk`; `swim` = 0 у неплавающих |
| `locomotion.ground/water/air` | bool | по чему умеет двигаться; `water` переключает набор клипов на `swim`/`swim_idle`, `air` — на `flight` |
| `use.tameable` / `use.rideable` | bool | приручается / ездовое |
| `use.products` | enum[] | что даёт живым: `milk`, `wool`, `feather`, `egg` |
| `drops[]` | {id,min,max,chance} | что падает с трупа |
| `voice` | string | id звука, на будущее |
| `notes` | string | человеческий комментарий: пробелы контента, странности пака |

> `drops[].id` — предмет из каталога `assets/items/items.json` (`raw_meat`,
> `hide`, `pelt`, `wool`, `feather`, `antler`, `tusk`). Идентификатор, которого
> нет в каталоге, ловит `TestMobLootIsReal`.

**Правило таблицы.** Хотя бы одна строка обязана иметь `chance: 1.0` — это
обязательная добыча: с любого зверя, даже с цыплёнка, что-то остаётся, иначе
убийство не даёт ничего. Она же держит количества маленькими (1-2 штуки), а
редкое лежит в остальных строках с низким шансом — ради них и охотятся.
Отсутствие такой строки — ошибка `Catalog.Validate`.

Как таблица разыгрывается (один розыгрыш на смерть, `mob.RollDrops`) и что
происходит с выпавшим дальше — см. [добычу в забеге](loot.md).

## 3. Что данные говорят про текущий контент

- **Дикие (5):** `fox`, `hare`, `deer`, `boar`, `black_grouse` — только у них полный
  набор анимаций (`hurt`/`death`), то есть только их и можно честно убивать.
  Остальные 25 — домашние, из фермерских паков.
- **Пары взросления (10):** `buffalo_cub→buffalo`, `calf→bull`, `colt→donkey`,
  `chick→rooster`, `duckling→duck`, `gosling→goose`, `goatling→goat`,
  `lamb→sheep`, `rabbit_cub→rabbit`, `foal→horse`.
- **Нападают (8):** `boar` и `goose` — первыми; `bull`, `buffalo`, `goat`, `dog`,
  `rooster`, `turkey` — в ответ; `fox` — только на мелочь из `prey`.
- **Водоплавающие (4):** `duck`, `drake`, `duckling` — с клипами `swim`;
  `goose`/`gosling` помечены водными, но плавательных спрайтов у них нет, и в
  воду движок их не выпускает.

**Пробелы контента** (зафиксированы в `notes`, не выдуманы данными): взрослой
свиньи, коровы и курицы в паках нет; у `cat`, `dog`, `rooster` нет клипа `idle`.

**Разобранные вопросы** (были помечены как `heuristic`): `walk_2` у `dog` и
`rooster` — это `sitting`, сидячая поза, переименовано; папка `calt`
переименована в `colt` (ослёнок); у `cat` стояния на месте нет и подменять его
нечем.

## 4. Баланс: здоровье, скорость, урон

Опора — **игрок: 50 hp** и шаг около 90 px/с. Отсюда три правила, по которым
расставлены числа:

- **Живучесть по массе.** Крупный рогатый скот держит больше игрока (буйвол 60),
  средний зверь — половину (кабан, осёл 30), мелочь падает с одного удара
  (цыплёнок, крольчонок 2–3). Корова заведомо живучее кота и птицы.
- **Скорость решает, догонишь ли.** Заяц (120) и олень (105) уходят от игрока —
  без лука их не взять; лиса (95) и лошадь (95) идут вровень; скот (42–48) и
  птица (24–40) догоняются шагом. `run` заполнен у всех, даже там, где клипа бега
  нет: движок ускорит походку (см. §5).
- **Урон меряется в ударах по игроку.** Буйвол 9 — шесть ударов до смерти, бык 8
  — семь, кабан 7 — восемь, но он единственный из животных нападает первым.
  Птица (1–2) щиплется, коза и лиса (3–4) кусают.

Урон и `threat.attacks` — одно утверждение, записанное дважды, поэтому их
расхождение ловится валидацией: `attacks` истинно тогда и только тогда, когда
`damage > 0`. Перезарядка удара общая для всех и живёт в коде, а не в данных.

## 5. Как это читает движок

Смысловые данные ничего не знают про то, какие клипы реально нарезаны, — стыкует
их рантайм ([internal/mob/animal.go](../../internal/mob/animal.go), `clipFor`) по
правилу деградации: **вид объявляет намерение, пак определяет исполнение**.

| намерение | клипа нет → |
|---|---|
| `threat.attacks` | рывок на ускоренном `walk` (`attack*`) |
| `speed.run` | `walk` с вдвое укороченным `FrameTicks` (`run*`) |
| `hurt` | вспышка спрайта на 24 тика |
| `death` | растворение и снятие с карты за 45 тиков |
| `locomotion.water` | вид в воду не заходит вовсе |
| нет `idle` | стойка не выбирается: зверь всегда в движении |

Последняя строка — не фолбэк, а отказ от него: подменять стояние первым кадром
походки нельзя, кот от этого замирает в позе шага. Нет анимации — нет состояния.

Характеров пять на все тридцать видов (`passive`, `skittish`, `territorial`,
`predator`, `tame`), и различия между зверями живут в данных, а не в коде.
Поэтому `species.json` можно балансировать, не трогая графику, а недостающие
анимации доснимать, не трогая баланс.

Карта попадает в автомат полем физики (`mob.Ctx.Field`, `internal/physics`):
пакет `mob` ничего не знает про worldgen, поле подставляет игровой слой. Стены,
скольжение вдоль них и этажи держит физика, зверю остаётся скорость.

Что зверь умеет в воде, выводится из вида и пака: `locomotion.water` пускает его
на мелководье (там бредут, ×0.6 к скорости), а глубокая вода требует ещё и клипа
`swim` — иначе он поплыл бы стоя. На макушку возвышенности любой зверь попадает
только по лестнице, и цель на другом этаже он не преследует: обходить обрыв
звери не умеют, и без этого правила хищник тёрся бы носом в скалу.

## 6. Точка опоры (`anchor`) и рамка (`bbox`)

Кадр — это коробка 32×32 (или 16/64), но зверь занимает в ней не всю площадь:
сверху пустота, снизу тень под лапами. Чтобы поставить животное на тайл, нужен
не размер кадра, а место, где у него земля.

- `anchor` — точка внутри кадра, которая совмещается с позицией существа в мире.
  По ней же идёт сортировка по глубине и привязка хитбокса.
- `bbox` — рамка непрозрачных пикселей: из неё берётся радиус тела.

Оба поля считает [tools/spriteanchor](../../tools/spriteanchor/main.go) по
пикселям и вписывает в `manifest.json` — вручную это 30 паков × 3 размера кадра.
`anchor.X` — середина рамки, `anchor.Y` — её низ, причём низ берётся только по
наземным анимациям (`idle`, `walk`, `sitting`): в `death` зверь лежит, в `swim`
сидит по ватерлинию, и земля по ним считалась бы неверно.

Данные производные от графики, поэтому лежат в сгенерированном манифесте, а не
здесь. Инструмент идемпотентен; запускать после `assetnorm`, который манифесты
перезаписывает.

## 7. Валидация

Проверяется тестами [internal/mob](../../internal/mob) (`go test ./internal/...`):

- ключ записи == имя папки == `art`, папка существует;
- значения enum'ов входят в `vocab`; биомы существуют в `assets/biomes`;
- `grows_into`/`young_form`/`spawn.with`/`threat.prey` ссылаются на известные виды;
- `attacks` истинно ровно тогда, когда `damage > 0`; `hp` и шаг положительны;
- каждый пак режется без ошибок и содержит все четыре направления;
- `anchor`/`bbox` посчитаны и лежат внутри кадра;
- каждому виду есть чем отрисовать любое состояние (проверка деградации);
- зверь без клипа `swim` в воду не заходит, без `idle` — не встаёт;
- таблицы спавна непусты, детёныши самостоятельно не выпадают.
