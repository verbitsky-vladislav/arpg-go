# Виды животных — описательные данные (`species.json`)

Каноничное описание формата [assets/mobs/animals/species.json](../../assets/mobs/animals/species.json):
что за зверь, дикий или домашний, нападает ли, во что вырастает, где водится.

---

## 1. Зачем отдельный файл

Рядом со спрайтами уже лежит `manifest.json`, но он описывает **только графику**
(размер кадра, направления, список анимаций) и **генерируется** нормализатором
`tools/assetnorm` — любые ручные поля в нём затрутся при перегенерации.

Поэтому смысловые данные живут отдельно:

| файл | что описывает | кто пишет |
|---|---|---|
| `<вид>/manifest.json` | кадры, размеры, анимации | генератор (`assetnorm`) |
| `animals/species.json` | вид, повадки, среда обитания, дроп | человек (баланс) |

Один файл на всех, а не по файлу на вид: 30 видов балансируются таблицей, а не
хождением по папкам. Формат **единый** — у каждого вида присутствуют все ключи,
даже пустые (`null`, `[]`, `0`). Отсутствующих ключей быть не должно: загрузчик
не подставляет умолчания, а валидатор ловит расхождение набора ключей.

Ключ записи == имя папки со спрайтами == `art`.

---

## 2. Поля

### Кто это

| поле | тип | смысл |
|---|---|---|
| `art` | string | папка со спрайтами внутри `assets/mobs/animals/` |
| `title.ru` / `title.en` | string | отображаемое имя |
| `family` | enum | `canine`, `feline`, `equine`, `bovine`, `caprine`, `suid`, `leporid`, `cervid`, `fowl`, `waterfowl`, `game_bird` — родня; по ней удобно вешать общие звуки, дроп, реакции |
| `size_class` | enum | `tiny`/`small`/`medium`/`large` — **смысловой** размер (масса, отбрасывание, приоритет y-сортировки). Пиксельный размер кадра берётся из `manifest.json`, здесь не дублируется |

### Домашнее / дикое и взросление

| поле | тип | смысл |
|---|---|---|
| `domestication` | enum | `wild` \| `domestic` |
| `stage` | enum | `adult` \| `young` |
| `grows_into` | id \| null | во что вырастает детёныш (`buffalo_cub → buffalo`) |
| `young_form` | id \| null | обратная ссылка: детёныш этого взрослого |

Ссылки должны быть симметричны; исключения (`drake` — второй взрослый для
`duckling`, `piglet` — взрослой свиньи в паке нет) отмечены в `notes`.

### Характер и агрессия

| поле | тип | смысл |
|---|---|---|
| `temper` | enum | `passive` — пасётся, от удара коротко убегает; `skittish` — убегает от игрока заранее; `territorial` — атакует при вторжении в радиус; `predator` — охотится на `threat.prey`, от игрока убегает; `tame` — держится рядом с игроком/двором |
| `activity` | enum | `day` \| `night` \| `any` — на будущий цикл суток |
| `threat.attacks` | bool | **может напасть** вообще |
| `threat.unprovoked` | bool | нападает первым, без удара по нему (кабан, гусь) |
| `threat.damage` | int | урон удара |
| `threat.sight` | int | радиус обнаружения, px мира |
| `threat.flee_hp` | float | доля hp, ниже которой удирает (`1.0` = убегает всегда, не дерётся) |
| `threat.prey` | id[] | на кого охотится (пищевая цепочка, только для `predator`) |

`attacks: true` при отсутствующем клипе `attack` — норма: анимация есть только у
кабана, остальным движок подставляет рывок на `walk` (см. §4).

### Среда обитания

Двухуровневая: биом (какая карта) + зона (какое место на карте).

| поле | тип | смысл |
|---|---|---|
| `habitat.biomes` | map id→вес | id каталога в `assets/biomes`; вес — относительная частота спавна именно в этом биоме |
| `habitat.zones` | enum[] | где внутри карты: `water`, `shore`, `meadow`, `woods`, `trail`, `plateau`, `farmyard` |
| `habitat.avoid` | enum[] | куда не заходить при блуждании (жёстче, чем «не спавнить») |
| `habitat.needs_settlement` | bool | спавнится только рядом с постройкой/фермой, не в чистом поле |

Зоны намеренно совпадают со слоями, которые **уже выдаёт worldgen**
(см. [layers_and_plateau.md](../worldgen/layers_and_plateau.md)), чтобы спавнеру
не потребовался свой анализ карты:

| зона | источник |
|---|---|
| `water` | заливка `water_color` / уровни `stageLevels` |
| `shore` | разрежённый слой `coast` (`grass_water`/`mud_water`) |
| `meadow` | `ground` (трава) без объектов сверху |
| `woods` | `ground` под объектами-деревьями |
| `trail` | `mud` (тропы `stageTrails`) |
| `plateau` | `plateau` (верх возвышенности) |
| `farmyard` | окрестности построек из `assets/locations` — **ещё не генерится** |

`cliff` (тело обрыва) в списке зон нет — туда никто не спавнится; в `avoid` его
указывать можно.

### Спавн, польза, дроп

| поле | тип | смысл |
|---|---|---|
| `spawn.group.min/max` | int | размер группы (овцы стадом, цыплята выводком) |
| `spawn.with` | id \| null | спавнится рядом со взрослым этого вида (детёныши при матке) |
| `stats.hp` | int | здоровье |
| `stats.speed.walk/run/swim` | int | px/с; `run` заполняется даже без клипа `run` — фолбэк ускоряет `walk`; `swim` = 0 у неплавающих |
| `locomotion.ground/water/air` | bool | по чему умеет двигаться; `water` переключает набор клипов на `swim`/`swim_idle`, `air` — на `flight` |
| `use.tameable` / `use.rideable` | bool | приручается / ездовое |
| `use.products` | enum[] | что даёт живым: `milk`, `wool`, `feather`, `egg` |
| `drops[]` | {id,min,max,chance} | что падает с трупа |
| `voice` | string | id звука, на будущее |
| `notes` | string | человеческий комментарий: пробелы контента, странности пака |

> `drops[].id` — временные слаги (`raw_meat`, `hide`, `pelt`, `wool`, `feather`,
> `antler`, `tusk`). Реестра предметов ещё нет (в `assets/items` только атласы
> PNG); при его появлении id сверить.

## 3. Что данные говорят про текущий контент

- **Дикие (5):** `fox`, `hare`, `deer`, `boar`, `black_grouse` — только у них полный
  набор анимаций (`hurt`/`death`), то есть только их и можно честно убивать.
  Остальные 25 — домашние, из фермерских паков.
- **Пары взросления (9):** `buffalo_cub→buffalo`, `calf→bull`, `calt→donkey`,
  `chick→rooster`, `duckling→duck`, `gosling→goose`, `goatling→goat`,
  `lamb→sheep`, `rabbit_cub→rabbit`, `foal→horse`.
- **Нападают (8):** `boar` и `goose` — первыми; `bull`, `buffalo`, `goat`, `dog`,
  `rooster`, `turkey` — в ответ; `fox` — только на мелочь из `prey`.
- **Водоплавающие (4):** `duck`, `drake`, `duckling` — с клипами `swim`;
  `goose`/`gosling` помечены водными, но плавательных спрайтов у них нет.

**Пробелы контента** (зафиксированы в `notes`, не выдуманы данными):
взрослой свиньи, коровы и курицы в паках нет; у `cat`, `dog`, `rooster` нет
клипа `idle`; папка `calt` — опечатка исходного пака от `colt`.

## 4. Как это читает движок

Смысловые данные ничего не знают про то, какие клипы реально нарезаны, — стыкует
их рантайм, по правилу деградации: **вид объявляет намерение, пак определяет
исполнение**.

| намерение | клипа нет → |
|---|---|
| `threat.attacks` | рывок на ускоренном `walk` + вспышка урона |
| `speed.run` | `walk` с увеличенным `FrameTicks` |
| `hurt` | мигание спрайта |
| `death` | фейд и исчезновение |
| `locomotion.water` | зона `water` для вида отключается |
| нет `idle` | первый кадр `walk` |

Поэтому `species.json` можно балансировать, не трогая графику, а недостающие
анимации доснимать, не трогая баланс.

---

## 5. Валидация

Проверяется (пока скриптом, дальше — `tools/assetcheck`):

- ключ записи == имя папки == `art`, папка существует;
- у всех видов **одинаковый набор ключей** (включая вложенные);
- значения enum'ов входят в `vocab`; биомы существуют в `assets/biomes`;
- `grows_into`/`young_form`/`spawn.with`/`threat.prey` ссылаются на известные виды
  и симметричны;
- предупреждения: `attacks` без клипа `attack`, `locomotion.water` без `swim`,
  отсутствие `idle`.
