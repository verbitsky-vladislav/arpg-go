# Отрисовка пространств (слои)

Статус: 🟡 спроектировано — в коде сейчас плоско (заливка+сетка), слои ещё не разложены
Связь с кодом: `internal/world` (`world.Draw`), `internal/engine/camera.go`,
`internal/assets` (загрузка тайлов/спрайтов), `internal/entity` (сущности)
Связь с дизайном: `../design/art-direction.md` (стиль/проекция), `../mechanics/locations.md`
(зоны/арены), `../mechanics/bosses.md` (арена «Плетёная Могила»)

Как рисуется **любое игровое пространство** — открытая зона, боссовая арена, хаб.
Модель послойная, **как в Necesse**: наклонный вид сверху ~65°, где есть «пол», то,
что лежит **ниже** роста, сами существа, **стены** с высотой, надземный слой
**выше** и **задний фон** за краями. Единый порядок отрисовки + сортировка по
глубине делают перекрытия правильными (существо заходит **за** стену и **перед**
тем, что ближе к камере).

> Это не «про арены» — это общий рендер всех пространств. Арена — частный случай
> (замкнутая комната со всеми слоями); открытая зона использует те же слои, просто
> без стен и надземного.

## Стек слоёв (сзади → вперёд)

Рисуем строго в этом порядке; всё, кроме фона и UI, — через `camera.WorldToScreen`.

```
   ┌─ 9. UI / HUD ─────────────── экранные координаты, поверх всего
   │  8. Свет / атмосфера ──────── затемнение, пятна света, виньетка, погода
   │  7. НАДЗЕМНОЕ («выше») ────── свисающие коконы, кроны, крыши, тяжи, мембрана
   │  ── проход с сортировкой по Y ───────────────────────────────
   │  6. Стены ────────────────── высокие, с якорем у низа (Y-sort с сущностями)
   │  5. Сущности ─────────────── игрок/мобы/босс/выводок/снаряды/дроп (Y-sort)
   │  4. Низкие объекты ───────── кладки, камни, лут на полу, помост (Y-sort)
   │  ──────────────────────────────────────────────────────────
   │  3. Напольные декали («ниже») паутина, лужи яда, тени существ, телеграфы
   │  2. Пол ─────────────────── тайлы поверхности, на которой стоят
   └─ 1. Задний фон («фон») ───── за краями комнаты: пустота/бездна, параллакс
```

| # | Слой | Что в нём | Через камеру? | Y-sort? |
|---|------|-----------|:---:|:---:|
| 1 | **Задний фон** | за границами пространства: тьма/бездна, дальний параллакс, «небо» | параллакс/нет | нет |
| 2 | **Пол** | тайлы земли/пола — поверхность, на которой стоят | да | нет |
| 3 | **Напольные декали** | паутина (`web_patch`), лужи (`venom_pool`), кровь, **тени существ**, тени-мишени телеграфов | да | нет |
| 4 | **Низкие объекты** | кладки яиц, камни, лут на земле, помост, ловушки | да | **да** |
| 5 | **Сущности** | игрок, мобы, босс, выводок, снаряды, «стоящий» дроп | да | **да** |
| 6 | **Стены** | вертикальные границы комнаты (высота + коллайдер) | да | **да** |
| 7 | **Надземное** | свисающие коконы, кроны, потолок/крыша, верхние тяжи, мембрана входа | да | (обычно поверх) |
| 8 | **Свет/атмосфера** | затемнение, пятна света (кладки/глаза), виньетка, партиклы, погода | да/экран | нет |
| 9 | **UI / HUD** | шкалы, панели, курсор | **нет** (экран) | нет |

Слои **4–6 рисуются одним проходом с общей сортировкой по Y** (см. ниже) — иначе
существо не сможет корректно заходить за стену/помост и перед ними.

## Ключевой приём — сортировка по глубине (Y-sort)

В наклонном виде сверху **глубина = экранная Y**: кто ниже на экране — тот ближе к
камере и рисуется **позже** (поверх). Поэтому всё, что имеет **высоту** (существа,
стены, объекты, помост), рисуется в один проход, отсортированным по **точке-якорю на
полу**.

- **Якорь** — «где объект касается пола» (низ хитбокса / пивот-стопы). У спрайтов
  боссов это `pivot`/низ кадра (метаданные в `<boss>.json`); у стены — её нижний край.
- Сортировка **стабильная** по возрастанию Y якоря, затем рисуем по порядку.
- **Плоские слои (1–3) в сортировке НЕ участвуют** — они всегда под ногами.
- **Надземное (7)** — по умолчанию всегда сверху; исключение — если это высокий
  объект-колонна, он может уходить в Y-sort как стена. Крыши/кроны над игроком —
  **делаем полупрозрачными, когда игрок под ними** (как Necesse прячет потолок в
  помещении), чтобы не терять персонажа.

### Высота и тень (прыжок/полёт)
Существо в прыжке **поднимается на экране** (сдвиг вверх, `height_offset` в
`<boss>.json`), но его **якорь и тень остаются на полу**:
- спрайт рисуется со сдвигом −height по экранной Y;
- **тень — отдельный напольный декаль** (слой 3), на позиции якоря, сжимается/светлеет
  с высотой (уже заложено: `shadows/…`, `shadow_leap`);
- **для Y-sort берётся якорь на полу**, а не поднятый спрайт — иначе прыгун
  «телепортируется» по глубине.

## Камера и координаты

`engine.Camera` — простой 2D-сдвиг без поворота/зума (`camera.go`):
`screen = world − camPos + view/2`.

- Слои **2–8** проходят через `WorldToScreen`.
- **Задний фон (1)** может иметь **параллакс** (двигается медленнее камеры) или быть
  статичным экранным.
- **UI (9)** — в экранных координатах, мимо камеры.
- Камера **клампится к границам пространства** (`Camera.Follow(target, w, h)` уже
  умеет): для арены границы = размер комнаты → камера не выходит за стены; для
  открытой зоны = размер зоны.

| **Хаб / точка отдыха** | декоративный | тайлы города | стены построек | крыши (прозрачны внутри) | частично |
| **Меню (фон)** | арт-задник | — | — | — | — |

### Пример: арена «Плетёная Могила» по слоям
- **1 Фон:** тьма с далёкими паутинными тяжами.
- **2 Пол:** тайлы шёлкового пола (`env/weaver_grave/floor/`).
- **3 Декали:** паутина (`web_patch`), ядовитые лужи (`venom_pool`), тени существ,
  тень-мишень прыжка.
- **4 Объекты:** центральный **помост**, 8 **альковов**, **кладки яиц** (светятся),
  коконы выводка (`eggsac`), лут-коконы.
- **5 Сущности:** Ткачиха, паучки, игрок, снаряды.
- **6 Стены:** восьмиугольный периметр из паутины (коллайдер), **мембрана входа**.
- **7 Надземное:** свисающие **коконы-жертвы** и верхние тяжи (над плоскостью боя —
  по ним не ходят; полупрозрачны, если игрок под ними).
- **8 Свет:** общий полумрак + зелёные пятна от кладок, красные точки глаз.

## Ассеты слоёв — тем же пайплайном, что боссы

Пол/стены/объекты/надземное **печёт процедурный генератор Go** (как `tools/weavergen`),
в той же наклонной проекции ~65°, чтобы стиль совпадал:

```
tools/envgen → assets/sprites/env/<space>/
   floor/ (тайлы, тайлятся по краям) · walls/ · dais.png · alcove.png ·
   hanging_cocoon.png (надземное) · entrance_membrane.png · props/…
```
Напольные FX (паутина, лужи, тени) уже испечены в `weavergen` → переиспользуются в
слое 3. Загрузка — `assets.Loader` (кеш PNG). Тайлы пола замащивают видимую область
камеры (рисуем только попавшие в кадр).
