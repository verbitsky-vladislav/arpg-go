# Умения (скиллы)

Статус: 🟡 черновик — 6 стартовых (по 1 на класс)
Связь: `tags.md`, `damage-and-defense.md`, `characters.md`

## Принципы

- **Уникальные, но переиспользуемые.** Скилл не заперт за классом — любой герой
  может его взять (Маг может махать «Расколом», Рыцарь — кинуть «Огненный шар»).
  Насколько эффективно — зависит от билда.
- **Масштабируются по тегам.** Атаки (Ближний/Дальний бой) — от оружия и атрибута;
  Чары — от силы заклинаний. Поэтому «чужой» скилл работает, но раскрывается
  только при вложениях в его теги (`tags.md`).
- **Теги решают прогрессию.** Пассивки единого дерева бустят скилл по его тегам.
- Каждый герой просто **стартует** с одним из этих скиллов — не владеет им
  эксклюзивно.
- **Стоимость и откат.** Скилл тратит **ману** (некоторые — **здоровье**) — это
  два ресурса игры со своим регеном (см. `characters.md`) — и/или имеет **откат**.
  Точные значения — на баланс.

## Базовая атака (кулак)

Каждый герой всегда имеет **базовую атаку — удар кулаком** (супер-ближний бой),
**без гема и сокета**. Это то, чем бьёшь **до** первой брони и скиллов, поэтому
правило «нет брони — нет скиллов» не блокирует старт.

- **Урон:** физический, слабый (масштабируется как Атака).
- **Дистанция:** очень короткая (вплотную).
- **Анимация:** `punch`, 16 кадров у каждого героя (`assets/sprites/heroes/<id>/punch/`).

Стартовый скилл-гем герой **имеет**, но чтобы его применять — нужен сокет (броня).
До этого — кулак.

## 💪 Сила

### Раскол *(старт: Рыцарь)*
- **Теги:** Ближний бой · Область
- **Что делает:** размашистый удар по дуге перед собой, задевает всех в секторе.
- **Урон / статус:** физический (от оружия); шанс **Раздробления** (ломает броню цели).
- **Роль:** контроль толпы вплотную, вскрытие брони под добивание.

### Вихрь *(старт: Дикарь)*
- **Теги:** Ближний бой · Область · Длительность
- **Что делает:** раскручивается и бьёт всех вокруг, пока держишь (канал).
- **Урон / статус:** физический (оружие); шанс **Кровотечения**.
- **Роль:** устойчивый урон по окружению; синергия с вампиризмом Дикаря.

## 🏹 Ловкость

### Пронзающая стрела *(старт: Следопыт)*
- **Теги:** Дальний бой · Снаряд
- **Что делает:** мощный выстрел, **пробивает насквозь** ряд врагов по линии.
- **Урон / статус:** физический (оружие), уклон в крит; шанс **Кровотечения**.
- **Роль:** пробой плотных линий с дистанции.

### Теневой рывок *(старт: Ассасин)*
- **Теги:** Ближний бой · Перемещение
- **Что делает:** мгновенный рывок сквозь цель с ударом при проходе.
- **Урон / статус:** физический (оружие), высокий крит; даёт мобильность/уход.
- **Роль:** сближение, бурст по одиночке, репозиционирование.

## 🔮 Интеллект

### Огненный шар *(старт: Маг)*
- **Теги:** Чары · Снаряд · Область · Огонь
- **Что делает:** летящий шар, **взрыв по площади** при попадании.
- **Урон / статус:** огонь (сила заклинаний); шанс **Поджога** (DoT).
- **Роль:** урон по толпе с дистанции, дожигание поджогом.

### Турель *(старт: Инженер)*
- **Теги:** Призыв · Длительность · Дальний бой
- **Что делает:** ставит автономную пушку — сама стреляет по врагам, пока стоит.
- **Урон / статус:** физический (техно), непрямой урон.
- **Роль:** контроль зоны, урон «пока сам кайтишь».

## Прицеливание (наведение)

Три режима:

| Режим | Как наводится | Скиллы |
|-------|---------------|--------|
| **В курсор** | летит/бьёт в направлении курсора | кулак, Раскол, Пронзающая стрела, Теневой рывок, Огненный шар |
| **Область вокруг себя (удержание)** | без наводки; бьёт вокруг героя, **пока держишь** (канал) | Вихрь |
| **Установка + авто** | ставится у героя, сама бьёт врагов **в своём радиусе** | Турель |

Правило: **всё, что не «область вокруг себя», наводится в курсор.** Спрайты
направленных скиллов поворачиваются по прицелу (`GeoM.Rotate`); радиальный Вихрь
симметричен; Турель наводит выстрелы на цель сама.

## Переиспользование: как это играется

Смысл: скилл даёт **возможность**, а билд (теги в дереве) — **силу**.

- **Маг берёт «Раскол»** → машет в ближнем бою. Слабо без оружия/Силы, но с
  вложениями в кластер «Ближний бой» — рабочий ближний маг-гибрид.
- **Рыцарь берёт «Огненный шар»** → кастует. Урон от силы заклинаний, которой у
  него мало, но через дерево можно добрать → «боевой маг» в латах.
- **Следопыт берёт «Турель»** → ставит пушку и кайтит вокруг — двойной источник урона.

## Слоты и сокеты

Скиллы вставляются в **сокеты на амуниции** (как в PoE), а не в абстрактные слоты.
Больше/лучше экипировки → больше активных скиллов и поддержек.

**Полный план сокетов по слотам:**

| Предмет | Сокетов |
|---------|:-------:|
| Броня (нагрудник) | 4 |
| Оружие | 2 |
| Сапоги | 2 |
| Перчатки | 2 |
| Шлем | 2 |

**Что кладём:** в каждый сокет — **скилл** ИЛИ **камень поддержки**, на выбор игрока.
**Связывание:** все сокеты одного предмета — **одна группа**; поддержки в группе
усиливают **скилл(ы)** этой же группы.

**Гибко, на усмотрение игрока.** Броня с 4 сокетами — это, например:
- 4 скилла (4 активных умения, но без бонусов поддержек),
- 1 скилл + 3 поддержки (один прокачанный скилл),
- любой микс. 4 поддержки без скилла — **бесполезны** (некого усиливать).

**Число сокетов случайно на дропе:** броня падает с **1, 2, 3 … до максимума**
сокетов — больше сокетов = ценнее предмет.

**MVP:** используем только слот **брони**. **Нет брони — нет сокетов — скилл
вешать некуда:** умения «включаются», лишь когда игрок найдёт нагрудник (завязка
на лут, см. `items.md`).

## Камни поддержки

Поддержка ставится в связанную со скиллом группу и **модифицирует** его. Пока —
**по одному очень простому камню на каждый тег**, супер-балансные (значения
плейсхолдерные, крутим на балансе). Два вида:

- **Усиление** — «+X% к эффекту тега» для скилла, у которого этот тег есть.
- **Добавление** (камни типов урона) — **добавляют** урон своего типа и **дают
  скиллу тег** (реализует «добавить стихию поддержкой» из `tags.md`).

| Тег | Камень поддержки (простой эффект, плейсхолдер) |
|-----|-----------------------------------------------|
| Атака | +20% урона атак |
| Ближний бой | +20% урона ближнего боя |
| Дальний бой | +20% урона дальнего боя |
| Чары | +20% урона чар |
| Область | +20% размера области |
| Снаряд | +20% урона снарядов |
| Перемещение | +20% дальности перемещения |
| Призыв | +20% прочности призванного |
| Миньоны | +20% урона миньонов |
| Аура | +20% эффекта ауры |
| Проклятие | +20% эффекта проклятия |
| Длительность | +20% длительности |
| Физический | +20% физ. урона |
| Стихия | +20% урона стихиями |
| Огонь | добавляет урон огнём (даёт тег Огонь) |
| Холод | добавляет урон холодом (даёт тег Холод) |
| Молния | добавляет урон молнией (даёт тег Молния) |
| Хаос | добавляет урон хаосом (даёт тег Хаос) |

> Поддержки = второй слой билд-крафта поверх дерева: **дерево** бустит по тегам
> глобально, **поддержки** — точечно на конкретный скилл (и могут менять его теги).

## Решено

- Урон **Турели** — физический (пока).
- Стоимость: скиллы тратят **ману/здоровье** (+ откат); значения — на баланс.
- Слоты — **сокеты на амуниции**; MVP = броня, нет брони → нет скиллов.
- **Базовая атака** — удар кулаком (без гема/сокета), супер-ближний бой: чем бьёшь до брони.
- **Прицеливание** — 3 режима: в курсор / область вокруг себя (удержание) / установка+авто (Турель).
- Сокеты **гибкие:** скилл ИЛИ поддержка на выбор; всё в предмете — одна группа;
  число сокетов на дропе случайно (1…макс).
- **Поддержки** — есть, по одному простому камню на тег.
