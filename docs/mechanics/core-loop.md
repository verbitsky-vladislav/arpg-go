# Core Loop — ядро геймплея

Сердце ARPG. Петля, которую игрок повторяет тысячи раз. Должна быть кайфовой
**сама по себе**, до всякого контента.

Статус: 🟡 заполняем вместе
Связь с кодом: internal/world, internal/entity, internal/combat

## Петля (минута к минуте)

```
        ┌──────────────────────────────────────────┐
        ▼                                            │
   ВСТРЕЧАЕШЬ мобов → БЬЁШЬ (умения/позиция) → они ПАДАЮТ,
   выпадает ЛУТ → ПОДБИРАЕШЬ/усиливаешься → идёшь ГЛУБЖЕ ──┘
                         (враги сильнее, награда жирнее)
```

Классическая ARPG-петля: **fight → loot → grow → harder fight**.

## Масштабы времени

| Масштаб | Что происходит | Что должно ощущаться |
|---------|----------------|----------------------|
| Секунды (2–5с) | удар, уклонение, срабатывание умения | отзывчиво, «сочно» |
| Минуты (1–3мин) | зачистка группы/комнаты, дроп, мелкое усиление | ритм «напряжение→разрядка» |
| Сессия (20–40мин) | продвижение по зоне, левелап, находка предмета | ощутимый рост силы |
| Мета (часы+) | билд, редкий лут, эндгейм-гринд | долгосрочная цель |

## Что должно быть кайфово на каждом шаге

- **Усиление:** _[мгновенно чувствуется? левелап/предмет меняет игру?]_
