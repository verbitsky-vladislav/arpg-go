# Предметы и лут

Статус: 🟡 черновик — **MVP: только базовые вещи**
Связь: `skills.md` (сокеты), `damage-and-defense.md` (защита),
`../progression/skill-tree.md` (атрибуты), `characters.md`

## Роль

Лут — топливо билд-крафта и гринда (пиллар «лут питает творчество»,
см. `../vision.md`). Особая роль брони: **без неё нет сокетов — нет скиллов**
(`skills.md`), поэтому первый нагрудник = ключевой момент.

---

## MVP: только БАЗА

Пока **никаких аффиксов и редкостей** — только базовые предметы. «База» =
предмет с врождёнными свойствами (защита/урон) + случайное число **сокетов**.
Всё бело-обычное (`Normal`).

### Тип защиты базы
Как в PoE, база доспеха бывает трёх видов — под атрибут:
**Броня** (Сила) · **Уклонение** (Ловкость) · **Энергощит** (Интеллект).
Выбор базы = выбор защитного профиля (см. `damage-and-defense.md`).

### Набор базовых вещей (MVP)

Доспехи — по **3 базы** на слот (по одной на тип защиты):

| Слот | Броня-база | Уклонение-база | Энергощит-база | Макс. сокетов |
|------|-----------|----------------|-----------------|:-------------:|
| **Нагрудник** | Латный нагрудник | Кожаная куртка | Мантия | 4 |
| **Шлем** | Шлем | Капюшон | Венец | 2 |
| **Перчатки** | Латные рукавицы | Кожаные перчатки | Тканевые перчатки | 2 |
| **Сапоги** | Латные сапоги | Кожаные сапоги | Тканевые туфли | 2 |

Оружие — по **1 базе на класс** (6 штук):

| Класс | Оружие | Макс. сокетов |
|-------|--------|:-------------:|
| Рыцарь | Меч | 2 |
| Дикарь | Двуручный топор | 2 |
| Следопыт | Лук | 2 |
| Ассасин | Кинжалы | 2 |
| Маг | Посох | 2 |
| Инженер | Гаечный ключ | 2 |

Итого MVP: **12 доспехов + 6 оружий = 18 базовых предметов.**

### Сокеты
- Число сокетов **случайно на дропе**: 1 … макс для слота. Больше = ценнее.
- В сокет — **скилл или поддержка** (`skills.md`).

### Оружие (база)
Даёт **базовый урон атак**, **скорость атаки** и **тип урона** (пока физ.).
Скиллы-Атаки масштабируются от оружия. Конкретные числа баз — на баланс.

## Инвентарь (MVP)

Только **панель экипировки** — по **одному слоту на каждый тип вещи**
(как «кукла» персонажа в PoE):

```
[ Оружие ] [ Нагрудник ] [ Шлем ] [ Перчатки ] [ Сапоги ]
```

Поднял вещь с земли → надел в её слот (старая, если была, освобождается).
**Рюкзак-сетка для хранения — позже**, сейчас только надевание.

## Откуда падает (MVP)

- **Мобы** — базовый источник (небольшой шанс).
- **Сундуки** — гарантированные точки лута.
- **Боссы** — жирный дроп.

(Масштаб по зонам/item level — позже.)

## Позже — НЕ в MVP

Спроектировано, но отложено (не делаем сейчас):
- **Редкости** Магический/Редкий/Уникальный и **аффиксы** (префиксы/суффиксы).
- **Крафт/реролл** аффиксов.
- **Валюта, обмен, продажа** лишнего.
- **Пулы и веса аффиксов, tier'ы по item level.**
- **Рюкзак-сетка** (Tetris-инвентарь) для хранения.
- Слоты Кольца / Амулет / Пояс (чистые статы, без сокетов).

## Связь с пилларами

- **Лут питает творчество:** база + сокеты — уже материал для сборки скиллов.
- **Каждый бой проверяет билд:** выбор типа защиты базы закрывает слабости.
- **Рост ощущается:** нашёл нагрудник с сокетами → включились скиллы.
