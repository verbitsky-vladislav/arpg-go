# `map_format v1` — выходной формат карты

`worldgen.spec.md §3, §9.1` ссылается на `map-spec.md`, которого в репозитории
нет. Поэтому формат зафиксирован здесь и реализован в `tools/worldgen/mapformat.go`.
Файл пишется генератором как `map.json` рядом с рендерами.

## Верхний уровень

```json
{
  "format": "map_format v1",
  "biome": "forest",
  "seed": 1,
  "width": 128, "height": 128, "tile_size": 16,
  "sheets": [ { "name": "...", "file": "...", "columns": 21, "tilecount": 651, "firstgid": 7243 } ],
  "water_colors": [ [63,115,158], [58,101,139], [53,87,120] ],
  "layers": { ... },
  "props": [ ... ],
  "markers": [ { "kind": "spawn", "x": 64, "y": 61 } ],
  "nav": { "w": 128, "h": 128, "cost": [ ... ] }
}
```

`sheets` упорядочены и несут `firstgid` (нумерация как в Tiled): глобальный id
тайла = `firstgid листа + локальный id`. Разрежённые слои ссылаются на лист по
индексу в этом массиве (`s`).

## Слои (`layers`) — 12 канонических, порядок отрисовки снизу вверх

| Слой | Хранение | Содержит |
|---|---|---|
| `liquid` | плотный `[]uint16` | вода/пустота |
| `liquid_shade` | плотный `[]uint8` | полоса глубины воды: индекс цвета в `water_colors` + 1 |
| `liquid_detail` | разрежённый | анимированная детализация воды (рябь) |
| `ground` | плотный `[]uint16` | нижний уровень |
| `ground_spots` | разрежённый | пятна покрытия |
| `coast` | разрежённый | переходы вода↔земля (аним) |
| `surface_liquid` | разрежённый | кувшинки |
| `plateau_shadow` | разрежённый | тень обрыва на нижнюю землю |
| `plateau` | плотный `[]uint16` | верхний уровень |
| `cliff` | разрежённый | грани обрыва |
| `stairs` | разрежённый | лестницы |
| `hangers` | разрежённый | лианы со свеса |

`props` вынесены на верхний уровень как список сущностей (не тайлов).

### Плотные слои

`[]uint16` длиной `width*height`, row-major. **Кодирование: `0` = пусто,
значение `v>0` = локальный id тайла `v-1`.** Смещение на 1 нужно, чтобы отличать
пустую клетку от тайла с id 0. Каждый плотный слой рисует из одного листа
(`liquid` — из роли `liquid`, `ground` — `ground_a`, `plateau` — `plateau`).
Ограничение v1: многолистовые плотные слои не поддерживаются.

Байтовые плотные слои (`liquid_shade`, `nav.cost`) — `[]uint8`, и в JSON они
уезжают строкой base64: так их пишет `encoding/json` для любого `[]byte`.
Длина после декодирования — те же `width*height` элементов row-major.

### `water_colors` и `liquid_shade` — цвет воды

Сплошного водного тайла в наборах нет, воду красит движок (`autotiling.md §5`).
`water_colors` — палитра от мели к глубине; `liquid_shade[i]` даёт индекс цвета
для тайла `i` (`1` = первый цвет палитры, самая светлая вода у берега; `0` — нет
данных, берётся последний цвет). Полосу считает `stageWaterShade`: расстояние до
суши, размытое шумом, плюс правило «вся внутренняя вода (пруды, реки) —
светлая». Карта без этого слоя красится одним последним цветом, как раньше.

### Разрежённые слои

Список клеток `{ "x", "y", "s", "t", "anim?" }`:
- `s` — индекс листа в `sheets`;
- `t` — локальный id тайла (без смещения);
- `anim` — `{ "frames", "stride", "ms" }`, если тайл анимирован.

## `props` — сущности

```json
{ "id": "Tree1", "file": "PNG/Objects_separated/Tree1.png",
  "x": 30, "y": 12, "w": 8, "h": 8, "anchor": [4,8], "sort_y": 19, "collides": true }
```

`x,y` — тайл верхнего-левого угла футпринта; `anchor` — низ-центр (точка на полу);
`sort_y` — ключ сортировки по глубине (рисуются вместе с игроком). Пропсы —
отдельные PNG, не часть атласа.

## `nav` — проходимость

Плотная сетка `cost` длиной `w*h`, `uint8`: `0` — непроходимо (глубокая вода),
`160` — мелководье (×0.6), `255` — обычная земля/плато.

## Рендер и отладочные выходы

Генератор пишет в `out/worldgen/<id>/`:
- `seed_1.png … seed_N.png` — карты на разных сидах, композит на настоящем арте
  (главная валидация: карты структурно похожи, но визуально разные);
- `debug_height.png`, `debug_moisture.png`, `debug_levels.png` — поля генерации;
- `map.json` — эта структура (для первого сида);
- `report.txt` — проверки E1–E12 с фактическими значениями.

Запуск: `go run ./tools/worldgen <biome-dir> [-seeds N] [-size N] [-scale N] [-out dir]`.
