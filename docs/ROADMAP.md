# Roadmap — Пиксельная ARPG

Ориентир: **Path of Exile** (hack&slash + гринд), но **мобы нападают на нас**.
Разные персонажи, оружие, умения, типы урона, механики защиты. Графика —
**пиксель-арт, делается кодом**: сущности рисуются процедурно (`gfx`/`art`),
герои — PNG-кадры, тоже сгенерированные кодом и вшитые через `//go:embed`
(`assets`/`anim`/`hero`). См. `tech/architecture.md`.

Двигаемся по этапам: каждый заканчивается запуском `go run .` и проверкой руками.
`[x]` — сделано.

---

## ✅ Этап 0 — Каркас (готово)

- [x] Слоёная структура пакетов (`internal/*`), без циклов импортов
- [x] Генерация пиксельных спрайтов в коде (`gfx` + `art`)
- [x] Камера и мир больше экрана (2000×2000), фоновая сетка
- [x] Игрок: движение WASD, прицел мышью, умение-снаряд (Fireball)
- [x] Характеристики `Stats`: жизнь, мана, броня, сопротивления, реген
- [x] Типы урона (Physical/Fire/Cold/Lightning/Chaos) + снижение (броня/резист)
- [x] Мобы 3 типов (Grunt/Brute/Zapper): преследуют и **бьют** игрока
- [x] Оружие и умение как отдельные системы (`item`, `skill`)
- [x] HUD (шары жизни/маны, счёт убийств), меню, смерть/респавн
